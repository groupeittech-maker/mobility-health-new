Tarification voyage

Le devis utilise d’abord le tarifaire ci-dessous (zone × durée) + surprimes âge, sauf si le produit définit une matrice tarifaire ou une grille finale dédiée. Codes moteur : INTRA_AFRIQUE, RSA_MAGHREB, EXTRA_AFRIQUE, INTER_AFRIQUE. Un pays peut être coché dans plusieurs zones si besoin (ex. intra + inter) : le devis utilise une priorité (RSA, puis Extra, puis Intra, puis Inter ; Intra l’emporte sur Inter pour les trajets intra→intra).
